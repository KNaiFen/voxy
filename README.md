Voxy is an LoD rendering mod for minecraft

## Forge 1.20.1 简体中文版本

从 [Releases](https://github.com/KNaiFen/voxy/releases) 下载不带 `-dev` 后缀的 JAR，放入游戏的 `mods/` 目录。需要 Java 21、Forge 47.x 和 Embeddium；发行包包含 Windows/Linux x86-64 原生库。

在游戏语言中选择“简体中文”，然后打开视频设置中的 Voxy 页面。设置名称、悬浮说明、选项状态、导入进度和常见命令提示均支持中文；其他语言继续使用英文。

开发包 `-dev.jar` 用于编译附属 Mod，不能作为游戏安装包。自动发行标签包含实际构建提交，以区分上游更新与本仓库的汉化改动。
